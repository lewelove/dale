# Contributing

Since I develop Datamile mostly by myself, there can be many desired, or even essential things not implemented in the current state. If you have any ideas or requests, or if you want to contribute with patches, please submit everything to issues and PRs respectively. I would be sincerely happy to read through, work on and/or merge them. I am also fully open to code critique and any structural improvements. I want to keep Datamile as fast, maintainable and open to new contributors as possible. If you have constructive criticism of the codebase for me to take action upon, please submit it to the issues as well.
